Einmalig: GitHub-Schlüssel hinterlegen

Am eigenen PC einfacher: „3D-Upload“ auf dem Desktop doppelklicken – dann geht es ohne Schlüssel, auch mit C4D-Dateien.

Für andere Geräte: Damit diese Seite Modelle in dein Repo legen darf. Der Schlüssel bleibt nur in diesem Browser gespeichert.

  1. Klick auf Schlüssel erstellen (öffnet GitHub).
  2. Bei Repository access „Only select repositories“ → 3d wählen.
  3. Bei Permissions → Contents „Read and write“ wählen, dann Generate token.
  4. Den Schlüssel (beginnt mit github_pat_) hier einfügen.
